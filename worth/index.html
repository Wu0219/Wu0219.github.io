怎么用：先在顶部选国家，点预设快速填一份，再逐项改成你自己的情况。得分 1.00 = 在所在国刚好对得起你的年限与付出；想提分，先看右侧「最值得改善的项」。
比较中西 offer：分别在两个国家各填一份，每填完一份点顶部「存入中西对照」，然后去 🌍 中西对照 标签页 —— 那里会算出「另一边要拿多少钱才追得平」，并把差额拆成薪资 / 工时 / 环境 / 成长 / 风险 / 期望六项。两边都建议打开「按税后口径计算」。
数据去哪了：你填的每一个数字都只存在你自己的浏览器里（localStorage），不会上传，服务端也没有任何接口。页面唯一的外部请求是 Cloudflare Web Analytics 的访问量统计（无 Cookie、不采集个人信息、不读取你填的内容）。想要完全零请求的版本，下载源码本地打开即可。
免责：这是一个主观权重模型，不是统计拟合。它回答「当下这一年划不划算」，不回答「五年后值不值」。别拿它做人生决策，拿它做体检。
